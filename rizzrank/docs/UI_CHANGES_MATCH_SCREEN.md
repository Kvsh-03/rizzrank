# UI Change: Game Match Screen – Remove Hardcoded Personality Tags

## Change

**Current:** The game match screen (battle/chat view) displays hardcoded personality attribute tags: "Night Owl" and "Cinephile".

**Update:** Remove these hardcoded tags from the GUI. They should not appear on the match screen.

**Reason:** These values are static and do not reflect the actual AI persona traits for the current match (e.g., height, age, hobbies, communication style), which are chosen randomly per match.
